# База Миро — панель управления
## Platform
web
## Stack
React, framer-motion и lucide-react из предоставленного пользователем JSX-фрагмента. Cloudflare Worker обслуживает сайт и закрытый прокси; Python aiohttp на BotHost выполняет операции. Общая SQLite база существующего бота.

## Задачи
Поиск участников по нику и ID, таймаут, снятие таймаута, роль-бан и восстановление ролей, баланс и история казино, отправка обычного текста в каналы и личные сообщения, аудит с фильтрами, управление доступом.
## Обязательное
Один сайт и общая база на dashboard.bazam1ro.ru и dashboard.bazam1ro.online. Чёрно-зелёный стиль; композиция из пользовательского скриншота Glassy Dashboard: узкая навигация, приветствие, большой центральный блок, вспомогательный блок и статистика. Не выдавать демонстрационные показатели за реальные. Консоль допускает только именованные операции, не Python/shell.
