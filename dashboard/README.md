# Панель Базы Миро

React-сайт на Cloudflare Workers, подключённый к существующему боту на BotHost. Оба домена используют одну базу бота. Сайт не содержит токена Discord и не подключается к SQLite напрямую.

## 1. Обновить бота

Рядом с `fufel.py`, `activity.py`, `economy.py` должны находиться новые `dashboard.py` и `moderation.py`. Загрузите обновлённые файлы и сохраните папку `static` приложения Discord. Перед обновлением сделайте резервную копию базы.

Сохраните существующий путь `ECONOMY_DB`. Если база уже находится в `/app/data/economy.sqlite3`, используйте именно его. Не переключайте путь на пустую базу. На BotHost постоянные данные должны храниться в `/app/data`.

## 2. Создать первые аккаунты

На своём компьютере в папке бота выполните `python setup_dashboard.py`. Скрипт попросит пароли для `tech` и `owner` без отображения на экране. Они должны содержать минимум 12 символов. Исходные пароли не сохраняются.

Скрипт создаст `%USERPROFILE%/.fufel-dashboard-secrets/bothost.json` и `bridge-key.txt` вне проекта. Не публикуйте эти файлы. Из JSON перенесите значения в переменные BotHost:

- `DASHBOARD_GUILD_ID`: `1544006188927156244`.
- `DASHBOARD_BRIDGE_KEY`: созданный ключ.
- `DASHBOARD_USERS_JSON`: созданная JSON-строка с хешами.

Перезапустите бота. Первые аккаунты создаются только при пустой таблице пользователей. После успешного входа переменную `DASHBOARD_USERS_JSON` можно убрать. Изменение этой переменной не сбрасывает существующие пароли.

## 3. Cloudflare

Добавьте `bazam1ro.ru` и `bazam1ro.online` в свой аккаунт Cloudflare и завершите настройку DNS у регистратора. В `wrangler.jsonc` уже указаны два поддомена и адрес бота. Если адрес BotHost изменится, исправьте `BOT_ORIGIN`.

В папке этого сайта выполните:

```powershell
npm ci
npx wrangler login
npx wrangler secret put BRIDGE_KEY
npm run deploy
```

В запрос `BRIDGE_KEY` вставьте содержимое локального `bridge-key.txt`: оно должно точно совпадать с `DASHBOARD_BRIDGE_KEY` на BotHost. Не вставляйте туда токен Discord.

Если Cloudflare ещё не видит оба домена, сначала завершите их подключение. Для предварительной публикации на `workers.dev` используйте отдельную копию конфигурации без `routes`; основной файл сохраняет целевые домены.

## 4. Проверить

Откройте сайт, войдите как `tech`. Проверьте реальный список участников, баланс и журнал. Затем создайте аккаунт саппорта с минимальными правами во вкладке «Доступ». Действия модерации и отправка сообщений выполняются только после подтверждения в панели.

Боту нужны Members Intent, доступ к серверу, права управления ролями и модерации участников. Роль бота должна находиться выше роли бана и ролей участников. Сообщения в ЛС могут быть запрещены настройками получателя.

## Поведение

- Роли сайта независимы от ролей Discord. Их разрешения проверяются на сервере.
- Сессия действует 8 часов. Смена пароля или прав отзывает текущие сессии пользователя.
- Консоль поддерживает только заданные команды модерации и монет, не команды ОС.
- Баланс и история используют существующую экономику казино. Повтор одного запроса не выдаёт монеты второй раз.
- При бане обычные роли сохраняются в базе, при разбане возвращаются. Управляемые интеграциями роли не удаляются. Роли выше бота остаются в очереди восстановления: исправьте иерархию и повторите разбан. Для старых банов без копии роли возвращаются вручную.
- Сообщение отправляется дословно, без подписи сотрудника; автор остаётся в аудите. Массовые упоминания не рассылают уведомления.
- Журнал содержит операции панели и действия бота, переданные через его `send_log`, а не всю историю Discord.

## Проверки разработки

`npm run build`, `npm run check:worker`; в папке бота — `python -m unittest discover -s tests -q`. Автоматические тесты используют подмену Discord и не наказывают настоящих участников.

## Локальный запуск без демонстрационных данных

`npm run dev` открывает тот же интерфейс входа и работает через настоящий API бота. Тестового пользователя demo и подставных показателей нет. Для подключения скопируйте `.env.example` в `.env.local` и задайте `DASHBOARD_BRIDGE_KEY`, совпадающий с переменной на BotHost. Секрет используется только сервером Vite, в браузер не передаётся. Без ключа сервер возвращает 503 «Панель ожидает подключения к боту». Для рабочего размещения используйте HTTPS Cloudflare и настройку BRIDGE_KEY из раздела 3.

При переключении разделов основные блоки появляются последовательно: 360 мс, задержки до 190 мс; режим уменьшения движения заменяет перемещение коротким изменением прозрачности.
