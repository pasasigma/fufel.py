# Фуфлыжник · Activity Beta

Python-бот и HTTP-сервер Activity работают в одном процессе. Node.js нужен только для пересборки интерфейса; готовый `static/assets/app.js` включён в пакет.

## Bothost

1. Загрузите содержимое этой папки целиком, включая `static`.
2. Python 3.10 или новее. Установка: `python -m pip install -r requirements.txt`.
3. Команда запуска: `python fufel.py`.
4. В панели окружения задайте `DISCORD_BOT_TOKEN`, `DISCORD_CLIENT_SECRET`, `ROBLOX_WEBHOOK_URL`. `DISCORD_CLIENT_ID` по умолчанию равен `1564664931343794366`.
5. Ваш HTTPS-адрес: https://bot-1794028033-8746-techieskings.bothost.tech. Настройте его маршрутизацию на порт `PORT` (по умолчанию 8080). При проверке до загрузки бета-версии адрес отвечал HTTP 404. Если Bothost выдаёт другой порт, укажите его в `PORT`.
6. Разместите `economy.sqlite3` на постоянном диске через `ECONOMY_DB`. Файл и соседние `-wal`, `-shm` нельзя терять при перезапуске/деплое. Бесплатный эфемерный диск не подходит для сохранения балансов.
7. Запускайте ровно один экземпляр бота; старый процесс остановите перед запуском бета-версии.

`.env.example` — список настроек. Файл `.env` автоматически не читается; используйте переменные панели хостинга. Токены не коммитьте.

## Discord Developer Portal

Откройте приложение 1564664931343794366. Включите Activities для приложения, настройте URL Mapping: `/` → `bot-1794028033-8746-techieskings.bothost.tech` (без `https://`). API и интерфейс обслуживаются с одного хоста.

Настройте Redirect URI в OAuth2 согласно актуальному мастеру Discord Activities. Client Secret из OAuth2 сохраните только в окружении хостинга. Включите Message Content Intent, Server Members Intent. Добавьте тестировщиков в App Testers и запустите Activity на сервере с ботом. Для публикации за пределами тестовой группы следуйте требованиям Discord Portal.

Боту нужны права управления ролями; его роль должна быть выше всех пяти продаваемых ролей. Административные роли с Administrator/Manage Roles не продаются. Проверьте остальные разрешения этих ролей вручную.

## Экономика

- Баланс отдельный на каждом сервере. Начальный баланс 0.
- Сообщение: +1, интервал 30 секунд. Команды `!`, вебхуки, сообщения ботов и сообщения, остановленные автомодерацией, не награждаются.
- Войс: +5 за полную минуту при двух неоглушённых людях. AFK-канал и боты исключены. Самозаглушённый микрофон разрешён. При выходе из подходящего войса неполная минута сбрасывается; время офлайн бот не начисляет.
- Покупки и спины сохраняются атомарно. Повтор запроса с тем же ключом не списывает монеты повторно.
- Роли выдаются через очередь в БД. Если Discord отклонил выдачу, право на роль сохраняется; выдача повторяется при открытии Activity.
- Приобретённая роль не выдаётся повторно после последующего ручного снятия; после бана роли восстанавливаются из сохранённой копии командой разбана; для старых банов без копии восстановление ручное.

## Рулетка

Цена 1000 монет. Шансы ролей по цене 35000/25000/15000/10000/5000: 1%/2%/3%/5%/10%.
Денежные призы: 1000 — 20%; 5000 — 5%; 10000 — 2.5%; 15000 — 1%; 30000 — 0.5%. Без выигрыша — 50%.
Повторная роль компенсируется её ценой в монетах. Указанные пользователем денежные призы дают в среднем 1000 монет за спин ещё до ролей: экономика намеренно щедрая и не сбалансирована на дефицит.

## Crash

Личный раунд, ставка 100–10000. Сервер заранее выбирает скрытую точку падения; текущий множитель растёт экспоненциально. Возможен мгновенный проигрыш на ×1.00. Максимум ×10, нужно забрать до падения; автоматического получения нет. Команда забрать учитывается по времени получения сервером, а не по устаревшему числу на экране. Закрытие окна не отменяет ставку.

Монеты не продаются за деньги и не выводятся. Все награды — виртуальные.

## Разработка

`npm install` и `npm run build` пересобирают интерфейс. `python -m unittest discover -s tests` запускает локальные тесты экономики. Для локального просмотра дизайна: `python -m http.server 8081 --directory static` (вне Discord вход и действия недоступны).

Настоящий вход Discord, выдачу ролей и работу на Bothost необходимо проверить после настройки хостинга.

## Кнопка запуска Activity

При старте бот проверяет глобальную команду типа PRIMARY_ENTRY_POINT и создаёт её с обработчиком Discord, если её нет. В русском интерфейсе новая команда называется «Играть». Остальные команды не удаляются. Ошибки регистрации выводятся в логи, повтор выполняется через минуту. Enable Activities должно быть включено. При обновлении этого исправления достаточно заменить activity.py и пересобрать бота.

## Обновление 8 ноября 2026

Команды работают через / с подсказками Discord, префикс ! отключён. /app открывает Activity из текстового канала сервера без подключения к войсу. Требуется discord.py >=2.6 и включённые Activities. Команды обновляются при запуске, без удаления команды входа.

/daily: 100 × номер дня серии, один раз за календарный день UTC+5. Пропуск сбрасывает серию; верхнего лимита дней нет. Серия сохраняется в economy.sqlite3. Для постоянного хранения задайте ECONOMY_DB=/app/data/economy.sqlite3.

Crash: шаг 0,01×, максимум 10×, средний множитель около 2,15×. Колесо: 7 секунд (системное уменьшение анимации сохраняется). Тема чёрно-зелёная. Магазин находится только во вкладке Магазин.

Роли покупаются по порядку 5000 → 10000 → 15000 → 25000 → 35000, каждая по полной цене. Предыдущие роли магазина снимаются после выдачи новой. Другие роли не затрагиваются. Выигрыш в рулетке может повысить ступень; повторная или более низкая роль компенсируется монетами. Старые приобретения учитываются. Если Discord не подтвердил выдачу/снятие, операция повторяется при обновлении приложения без повторного списания.

После обновления GitHub: BotHost → Репозиторий → Сохранить и пересобрать. Ссылка и ветка main прежние. Баланс и базу данных не удалять.


## Crash и подсказки команд

Crash: 2% результатов ниже 1,30×; 95% от 1,30 до 3× с треугольным распределением и пиком около 1,80×; 3% от 3 до 10×. Шаг 0,01×. Это вероятности многих раундов, а не гарантия отдельного результата.

Slash-команды регистрируются отдельной задачей on_ready, независимо от веб-сервера и Activity. Бот обновляет только команды каждого сервера. После успешной регистрации удаляет известные глобальные дубли slash-команд; команду запуска Activity и посторонние команды сохраняет. При ошибке повторяет попытку через минуту. В логах ищите `Slash: команды готовы на сервере`. Если команды не видны, проверьте установку приложения на сервер с applications.commands и разрешение «Использовать команды приложений», а также ограничения в Настройки сервера → Интеграции → бот. Команду выбирают из подсказок / в текстовом канале сервера.
