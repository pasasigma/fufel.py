# fufel.py

Discord-бот с модерацией и уведомлениями об обновлениях Roblox.

Python 3.10+. Установите зависимости: `python -m pip install -r requirements.txt`.

Задайте переменные окружения `DISCORD_BOT_TOKEN` и `ROBLOX_WEBHOOK_URL` в настройках хостинга.

Запуск: `python fufel.py`.

Для сохранения счётчика обновлений нужен постоянный диск для `roblox_updates.json`.
